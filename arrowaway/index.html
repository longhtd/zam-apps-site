About the game

Arrow Away is a quick, satisfying puzzle. Every arrow points one way. Tap it and it slides off the board, but only if nothing is in its path.

Work out the right order and clear the whole board, one level at a time.

How to play

  1. Tap an arrow to slide it in the direction it points.
  2. An arrow cannot move if another arrow blocks its path.
  3. Clear every arrow from the board to finish the level.
  4. Use boosters and daily challenges when a board gets tricky.
